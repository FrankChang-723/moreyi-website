# MoreYi® Website

全车系汽车零配件供应商 | Full-Range Auto Parts Supplier

Multi-language (6 languages) static website for MoreYi brand auto parts.

## Deployment

Static HTML — deploy to any static host:
- **Vercel**: [vercel.com/drop](https://vercel.com/drop) — drag `index.html`
- **Netlify**: [app.netlify.com/drop](https://app.netlify.com/drop)
- **GitHub Pages**: Push to `main` branch, enable in repo Settings

## Languages
🇨🇳 中文 | 🇬🇧 English | 🇷🇺 Русский | 🇸🇦 العربية | 🇫🇷 Français | 🇩🇪 Deutsch

## Structure
- `index.html` — Single-page app with embedded i18n dictionary (838 entries)
- Category tabs filter 22 products across 13 categories
- Specs table, FAQ, contact form all multi-language
